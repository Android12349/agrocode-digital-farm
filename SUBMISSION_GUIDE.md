# АгроКод — запуск, проверка и подача

## 1. Быстрый запуск

Откройте PowerShell в папке проекта и выполните:

```powershell
python -m http.server 4173 --directory dist
```

После сообщения `Serving HTTP...` откройте в браузере:

```text
http://localhost:4173
```

Остановить сервер: `Ctrl+C` в окне PowerShell.

Если команда `python` не найдена, игру можно открыть двойным кликом по `dist/index.html`, но проверка через HTTP-сервер предпочтительнее: так она работает почти так же, как после публикации.

## 2. Что проверить перед публикацией

Пройдите игру минимум два раза:

1. На стартовом экране открывается окно «Как играть».
2. Кнопка «Начать смену» переводит к первому событию.
3. После каждого выбора меняются показатели: урожай, бюджет, технологии и команда.
4. Отображаются все 8 событий.
5. После последнего события появляется итоговый профиль.
6. «Сыграть ещё раз» запускает новую смену.
7. После обновления страницы сохраняется лучший результат.
8. Проверьте ширину окна телефона через DevTools — интерфейс не должен выходить за экран.
9. В DevTools → Console не должно быть красных ошибок.

## 3. Публикация в GitHub

Создайте на GitHub пустой репозиторий, например `agrocode-digital-farm`. Не добавляйте README или `.gitignore`: они уже есть локально.

В папке проекта выполните, подставив свой GitHub-логин:

```powershell
git branch -M main
git remote add origin https://github.com/YOUR_LOGIN/agrocode-digital-farm.git
git push -u origin main
```

Если `origin` уже существует:

```powershell
git remote set-url origin https://github.com/YOUR_LOGIN/agrocode-digital-farm.git
git push -u origin main
```

## 4. Публикация игры

Для конкурсной заявки нужен HTTPS-адрес, который открывается без авторизации. Подойдут:

- GitHub Pages;
- Cloudflare Pages;
- Netlify;
- Vercel;
- публичный ChatGPT Site.

Для GitHub Pages удобно использовать ветку `gh-pages` либо GitHub Actions. Важно публиковать содержимое папки `dist`, чтобы `index.html` находился в корне опубликованного сайта.

После публикации откройте ссылку в режиме инкогнито. Если игра требует входа — ссылка для экспертов не подходит.

## 5. Что приложить к заявке

Минимальный комплект:

- PDF-презентация на 8–10 слайдов;
- ссылка на работающую игру;
- ссылка на GitHub;
- короткое видео или GIF прохождения как резерв;
- при возможности — ZIP исходников.

В форму загружается файл с решением. Ссылка на опубликованную игру добавляется в поле для ссылки на решённое кейсовое задание.

## 6. Короткое описание проекта для формы

**АгроКод: спаси цифровую ферму** — короткая браузерная стратегия, в которой пользователь управляет цифровым сельхозпредприятием и принимает восемь решений в условиях климатических, технических, продуктовых и киберрисков. Решения влияют на урожай, бюджет, технологическое развитие и доверие команды. Игра знакомит ИТ-специалистов с задачами агротеха через понятную интерактивную механику. MVP адаптивен, не требует авторизации и готов к интеграции на платформу РСХБ.Цифра через iframe.

## 7. Важно перед отправкой

Не отправляйте форму, пока одновременно не готовы:

- публичная ссылка на игру;
- GitHub-репозиторий;
- презентация в PDF;
- заполненные личные данные и сведения о вузе;
- финальная проверка файлов и ссылок.
