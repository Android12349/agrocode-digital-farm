# АгроКод: спаси цифровую ферму

Короткая браузерная стратегия для стипендиального конкурса РСХБ.Цифра 2026/27.

Игрок принимает восемь управленческих решений и балансирует четыре показателя цифровой фермы: урожай, бюджет, технологии и доверие команды.

## Запуск

Проект не требует сборки или зависимостей. Поднимите любой статический HTTP-сервер из папки `dist`:

```bash
npx serve dist
```

## Возможности MVP

- восемь событий из агротеха, ИТ, кибербезопасности и продуктовой разработки;
- три варианта решения для каждого события;
- четыре динамических ресурса;
- четыре итоговых профиля игрока;
- сохранение личного рекорда в `localStorage`;
- адаптивный интерфейс;
- интеграция с родительской страницей через `postMessage`;
- Web Share API и копирование результата.

## Встраивание

```html
<iframe
  src="https://example.com/agrocode/"
  title="АгроКод: спаси цифровую ферму"
  width="100%"
  height="820"
  allow="clipboard-write"
></iframe>
```

После окончания игры iframe отправляет родительской странице сообщение:

```js
{
  type: "agrocode:finished",
  score: 78,
  profile: "Архитектор цифровой фермы",
  stats: { harvest: 75, budget: 62, technology: 91, trust: 84 }
}
```

Родительская страница может запустить новую игру сообщением `{ type: "agrocode:start" }`.

## Конкурсная задача

РСХБ.Венчурная студия — «Веб-игра для платформы РСХБ.Цифра».

MVP демонстрирует концепцию, базовую игровую механику и техническую готовность к встраиванию через iframe.
